poeggi's iOS Shortcuts

Open website on iPhone or iPad and tap Install.

Install goes to iCloud and takes one tap. That link depends on Apple, so every shortcut is also mirrored here as the signed file Apple produced.

Mirror downloads that file. Safari puts it in Files rather than opening it, so tap it there once to import it into Shortcuts. Use it if the iCloud link ever stops working.

Every shortcut is built by hand in the Shortcuts app. Each one is also kept as a readable XML property list in the repo, which is what makes it rebuildable if both the link and the signature expire.
